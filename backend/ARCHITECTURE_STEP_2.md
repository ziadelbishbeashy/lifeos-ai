# LifeOS Architecture Step 2

This checkpoint adds security hardening and a repeatable test foundation without changing the current database schema or user-facing features.

## Included

- Global CSRF protection for form and JavaScript POST requests
- Secure response headers and request identifiers
- Friendly 400/403/404/413/500 responses
- Upload-size error handling
- Testing fixtures for isolated SQLite tests
- Authentication, route-protection, and security tests
- Flask-Migrate remains enabled through the application factory

## Database migration rule

Do not run an autogenerated migration against the existing SQL Server database yet. The existing schema must first be captured as a reviewed baseline migration. Until that baseline is created, keep `AUTO_CREATE_DB=true` only for local development and do not use `db.create_all()` in production.

## Commands

```bash
pip install -r requirements.txt
python app.py
pytest
```
