LifeOS AI Cost & Observability Foundation
=========================================

BASE EXPECTATION
- Apply after I21.2 Intelligent Academic Schedule if that patch is not already in your local repo.
- Patch is architecture-preserving and contains no frontend/public files.

PURPOSE
- Capture exact provider-reported token usage for Gemini generation calls.
- Capture Gemini Document Brain embedding input-token usage.
- Calculate deterministic provider costs from configurable pricing.
- Store append-only usage events without allowing telemetry to commit workspace mutations.
- Add authenticated user-scoped AI usage summary/recent APIs.
- Keep normal Analytics focused on product/workspace analytics.
- Put token/cost monitoring on a separate Analytics development page: /analytics/ai-usage.
- Add optional privacy-conscious LangSmith LLM tracing.
- Preserve current AI behavior; no thinking-budget/model-routing behavior is changed yet.

MANUAL CHECK
1. Use Document Brain Analyze or Ask LifeOS.
2. Open Analytics.
3. Click "AI Usage (Development)".
4. Verify calls, input/output/thinking/cached tokens and provider cost appear.
5. Click "Back to Analytics" to return to normal workspace analytics.
6. Optionally enable LangSmith in backend .env and repeat a request.

NOTES
- The AI Usage page is deliberately separate from normal Analytics and can be removed later without removing backend metering.
- No new sidebar page/module was added.
- Historical calls made before this migration cannot be reconstructed exactly.
- Prompts/model outputs are NOT stored in AIUsageEvent.
- Custom LangSmith tracing intentionally does not send raw prompt/output content.
- Unknown future model pricing is reported as unknown unless configured; it is not guessed.
