# PostgreSQL target

Use PostgreSQL locally and in integration tests so database semantics match Neon.

The historical Alembic chain contains SQL Server-specific autogenerated
revisions. **Do not replay that old chain on a fresh PostgreSQL/Neon database.**

Foundation V2 first proves the current SQLAlchemy metadata on PostgreSQL. After
that, freeze one reviewed PostgreSQL baseline and make every new migration
portable from that baseline forward.
